# Roadmap

The initial framework covers navigation, checkpoint continuity and adaptation.
The [phase ledger](docs/agent_framework/PHASE_STATUS.md) records qualification
and remaining verification.

## Subsequent work

- Broaden wheel coverage with portable Linux builds and additional CPython targets.
- Add held-out seed sets and workload-specific metrics as benchmarks evolve.
- Design FL-Economy with observations from the authoritative district markets.
- Separate policy memory from engine persistence in FL-Memory.
- Evaluate appropriate public observations and boundaries for FL-Social.
- Specify scheduling and information isolation before implementing FL-MultiAgent.
