# FAULTLINE - A World That Remembers

## Reproducible simulation demo

This demonstration follows one procedural world through
365 simulated days.

The world is generated from seed 12345. Factions compete
for territory, NPCs travel and participate in operations,
and the economy evolves through the authoritative simulation.

The world is saved after day 30, loaded again, and advanced
for another 335 days.

A separate uninterrupted run advances the same initial
world for 365 days.

Both paths produce identical final StateHash values
and identical SHA-256 save-file digests.

## Reproduce the experiment

Tested engine revision:

    96fcb11cf769c4f8d63c87b482478d5031905a35

Use the recorded revision when reproducing the exact
historical hashes.

Clone and build:

    git clone https://github.com/LuCa1506s/FAULTLINE.git
    cd FAULTLINE
    git checkout 96fcb11
    cd FAULTLINE_GAME_V1
    cmake -S . -B build-release -G Ninja -DCMAKE_BUILD_TYPE=Release
    cmake --build build-release

Create an output directory:

    mkdir demo-output

Run the initial world visualization:

    ./build-release/faultline_map2d --seed 12345 --output demo-output/day000.svg

Simulate and save the first 30 days:

    ./build-release/faultline_sim --seed 12345 --days 30 --save demo-output/day30.flsave

Render the intermediate state:

    ./build-release/faultline_map2d --load demo-output/day30.flsave --output demo-output/day030.svg

Load the checkpoint and simulate another 335 days:

    ./build-release/faultline_sim --load demo-output/day30.flsave --days 335 --save demo-output/day365_resumed.flsave

Run the independent uninterrupted simulation:

    ./build-release/faultline_sim --seed 12345 --days 365 --save demo-output/day365_direct.flsave

Render the final state:

    ./build-release/faultline_map2d --load demo-output/day365_resumed.flsave --output demo-output/day365.svg

Inspect both final saves:

    ./build-release/faultline_savecheck --inspect demo-output/day365_resumed.flsave
    ./build-release/faultline_savecheck --inspect demo-output/day365_direct.flsave

On Linux, compare their SHA-256 digests:

    sha256sum demo-output/day365_*.flsave

On Windows PowerShell, use:

    Get-FileHash demo-output/day365_*.flsave -Algorithm SHA256

On Windows, append .exe to the executable names.
See the engine README for the portable Windows toolchain.

## Provenance and limitations

The maps are generated by FAULTLINE itself, not imported
geographical data or promotional artwork.

The original recorded run used Windows Release binaries
built with GCC 16.2.0 from the tested clean GitHub clone.

The initial SVG represents raw generated-world data.
Later SVGs visualize actual persisted runtime states.

This is a headless strategic simulation demonstration,
not a complete playable game or a production renderer.

The recorded save equality applies to this seed, scenario
and tested build. Cross-platform reproduction of the
exact save digest requires separate verification.

The binary save files are not included in this demo
directory; the commands above regenerate them.
